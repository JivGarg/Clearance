# Clearance frontend

Next.js (App Router, Cache Components) + Tailwind v4. Part of the Clearance monorepo.

Commands, architecture notes and status live in the repo root: see [`../CONTEXT.md`](../CONTEXT.md).

```bash
npm run dev      # http://localhost:3000, sign in with a demo account
npm run build
npm run lint
```

This Next.js version differs from older releases. Before changing routing, caching or auth code,
read the matching guide under `node_modules/next/dist/docs/` (see `AGENTS.md`).
